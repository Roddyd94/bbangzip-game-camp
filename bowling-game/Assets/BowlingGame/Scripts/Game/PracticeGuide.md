# 단계별 볼링 플레이 데모

`Assets/BowlingGame/Scenes/BowlingHallPractice.unity`를 열고 Play를 누릅니다. `BowlingHall`을 복사한 씬이며, 1번 레인에서 한 명이 10프레임을 진행합니다. 나머지 레인은 배경으로 사용합니다.

## 조작 순서

1. 공 출발 위치: 레인 중심에서 좌우 0.4m 안에서 이동합니다.
2. 투구 각도: 정면 기준 -8~8도로 발사 방향을 정합니다.
3. 투구 세기: 0~100%를 출발 속도 4~12m/s로 변환합니다.
4. 회전 방향: 정방향 구름의 회전축을 -90~90도로 기울입니다. 0도는 정방향 구름이고, 부호에 따라 휘어지는 방향이 달라집니다.
5. 회전 세기: 추가 각속도를 0~60rad/s로 설정합니다.
6. 준비 화면에서 한 번 더 확인하면 투구합니다. 결과 판정과 핀세터 작동이 끝나면 다음 투구로 넘어갑니다.

각 단계에서 키를 누르고 있거나 화면 슬라이더를 움직여 값을 조절합니다. 청록색 화살표는 투구 방향이며, 투구 세기에 따라 길이가 2~6m로 바뀝니다. 주황색 직선은 회전축이고, 같은 색의 곡선 화살표는 축 주위를 도는 회전 방향입니다. 회전 세기가 클수록 곡선이 길게 감기며, 0%에서는 추가 회전 화살표를 숨깁니다.

| 동작 | 키보드 | 게임패드 / 화면 |
| --- | --- | --- |
| 현재 값 조절 | A/D, W/S 또는 방향키 | 왼쪽 스틱, D-pad / 슬라이더 |
| 다음 단계·투구 | Enter 또는 Space | 아래쪽 버튼 / 다음·투구하기 |
| 이전 단계 | Backspace | 오른쪽 버튼 / 이전 |
| 새 경기 | R | Start / 새 경기 |
| 카메라 전환 | C | 오른쪽 숄더 / 카메라 |

경기 중 R을 누르면 진행 중인 투구와 핀세터 동작도 취소하고 새 경기를 시작합니다. 오른쪽 점수판에는 기존 점수·프레임 이벤트가 반영됩니다.

## 역할 분리

| 파일 | 책임 |
| --- | --- |
| `BowlingSession.cs` | 단계 전환, 투구 시작, 레인 이벤트와 데모 진행 연결 |
| `BowlingInput.cs` | Input System 액션을 읽고 입력 이벤트 전달 |
| `BowlingShot.cs` | 조작 단계와 투구 설정값, 속도·회전축 계산 |
| `BowlingCamera.cs` | 준비·추적·핀 관찰 및 세 가지 시점 |
| `BowlingHud.cs` | 단계 설명, 값, 슬라이더, 버튼 및 경기 상태 표시 |
| `BowlingAimPreview.cs` | 투구 방향과 회전축 표시 |
| `BowlingSweeperCollider.cs` | 애니메이션 본을 따라 스위퍼의 물리 충돌체 이동 |

입력 액션은 `Assets/BowlingGame/Input/BowlingControls.inputactions`에서 수정합니다. 컴포넌트 연결은 씬의 Inspector에 명시적으로 저장합니다. 투구·회전 표시는 `Lane.prefab`의 `Aim Preview` 아래에 있으며, 모든 Line Renderer는 `Use World Space`를 끈 로컬 좌표를 사용합니다. 회전축과 곡선은 공 중심을 기준으로 배치하고, 화살촉 날개는 축 방향으로 가로로 펼칩니다. 주황색 회전선은 이전 대비 3배 굵기로 표시하고, 곡선 반지름은 공 반지름 약 0.109m에 가까운 0.15m입니다. `PreviewOverlay.shader`는 카메라 깊이 텍스처를 비교해 가려진 부분을 낮은 채도로 표시합니다. 데모 카메라의 Depth Texture가 켜져 있어야 앞뒤 색이 구분됩니다.

기존 미완성 클래스에 추가한 코드는 `연습 모드 구현` region에 있습니다. `BowlingBall`은 투구 물리, `BowlingPinSetter`는 남은 핀 보존·스위핑·재배치, `BowlingPin`은 데모용 기울기 판정을 담당합니다. 데모 전용 옵션은 이 씬에서만 활성화했습니다. 레인의 심판·블랙보드·외부 이벤트 발행 구조를 그대로 사용합니다.

## 물리 시연의 범위

레인 바닥에는 매끄러운 BoxCollider를 사용하고 거터와 말단 포획 공간은 단순한 박스들로 구성했습니다. LaneEnd의 감지 트리거는 하나입니다. 핀은 기존 저해상도 충돌 메시를 사용합니다.

회전은 Rigidbody의 각속도에 반영하며, 눈으로 방향 차이를 확인할 수 있도록 회전축과 세기에 따른 횡방향 힘도 적용합니다. 실제 오일 패턴과 볼 재질에 따른 마찰 모델은 구현하지 않은 데모용 근사입니다. 핀은 25도 이상 기울거나 레인 아래로 떨어지면 넘어진 것으로 판단합니다.

공이 정지·이탈하거나 제한 시간을 넘긴 경우에도 결과를 판정해 진행이 멈추지 않도록 했습니다. 핀세터는 남은 핀을 들어 올려 보존한 뒤 스위핑하고, 프레임이 끝나면 10개를 다시 배치합니다. 데모 Animator Override는 원본 클립을 복제해 빈 AnimationEvent를 제거한 버전을 사용합니다.
