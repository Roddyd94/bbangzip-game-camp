# 02주차 볼링 — 프레임 진행과 점수 계산

제공된 볼링장에서 **투구 결과를 기록하고, 10프레임의 점수와 다음 투구 상태를 계산**합니다. 경기 규칙 담당으로서 핀 결과를 점수판과 다음 투구 준비에 연결하는 훈련입니다.

## 1. 프로젝트 세팅

1. Starter Kit가 배포되면 원본 저장소를 Fork하고, 개인 Fork를 복제합니다. 이미 복제했다면 `upstream` 등록 여부를 확인한 뒤 `fetch`부터 진행합니다.

   ```powershell
   git clone <개인-Fork-URL> bbangzip-game-camp
   cd bbangzip-game-camp
   git remote add upstream https://github.com/Roddyd94/bbangzip-game-camp.git
   git fetch upstream
   git switch -c work/02 upstream/week/02-bowling
   ```

2. Unity Hub에서 `bowling-game/`을 엽니다. 에디터는 `ProjectSettings/ProjectVersion.txt`에 지정된 **Unity 6000.6.7f1**을 사용합니다.
3. 패키지 복원이 끝나면 [BowlingHallPractice 씬](bowling-game/Assets/BowlingGame/Scenes/BowlingHallPractice.unity)을 열고 Play합니다. 1번 레인에서 방향키로 값을 조절하고 Enter 또는 Space로 다음 단계로 넘어갑니다. 준비 화면에서 한 번 더 누르면 투구합니다. [전체 조작법](bowling-game/Assets/BowlingGame/Scripts/Game/PracticeGuide.md)

## 2. 과제

### 2-1. 목표

[BowlingReferee.cs](bowling-game/Assets/BowlingGame/Scripts/TODO/BowlingReferee.cs)의 `TryResolveRoll`에서 투구 결과와 다음 진행을 판정하고, `RecalculateScores`에서 프레임 점수와 누적 점수를 계산합니다.

### 2-2. 검증 방식

Unity의 **Tools → Bowling → Validate Lane Architecture**를 실행한 뒤, 연습 씬에서 투구 결과가 점수판에 반영되고 다음 투구가 열리는지 확인합니다.

### 2-3. 제출 방식

구현을 개인 Fork에 푸시하고, Discord에 작업 브랜치 링크와 핵심 구현 설명 3~5줄을 공유한 뒤 짧게 시연합니다.

### 2-4. 제공 API

| API | 역할 |
| --- | --- |
| `board.CurrentFrameNumber`, `board.CurrentRollNumber`, `board.GetFrame(number)` | 현재 진행과 해당 프레임의 투구 기록 조회. 번호는 1부터 시작합니다. |
| `board.StandingPinMask`, `standingPinMask` | 각각 투구 전과 투구 후에 서 있는 핀입니다. 비트 0~9는 1~10번 핀에 대응하며, 마스크 `0`은 남은 핀이 없다는 뜻입니다. |
| `CountPins(mask)`, `IsSplit(mask)` | 마스크에 표시된 핀 수와 스플릿 여부 조회 |
| `BowlingRollRecord`, `BowlingRollDecision` | 이번 투구의 기록과 다음 상태를 각각 표현. `ShouldResetRack`은 다음 투구 전에 핀 10개를 다시 세울지, `NextRollStandingPinMask`는 다음 투구 시작 시 서 있어야 할 핀을 나타냅니다. |
| `board.Record(roll, decision)` | 투구를 저장하고 진행 상태를 갱신. 호출은 제공 코드에 들어 있습니다. |
| `board.Frames`, `frame.Rolls` | 점수 계산에 사용할 기록. 결과는 `frame.Score`, `frame.IsScoreConfirmed`, `frame.TotalScore`, `board.TotalScore`에 반영합니다. |

### 2-5. 목표 상세

투구 조작, 공·핀 물리, 핀 감지·재배치, 점수판 UI와 새 경기 초기화는 제공됩니다. 두 TODO를 구현하기 전에도 공을 던질 수 있지만, 결과가 기록되지 않아 다음 투구로 진행하지 않습니다.

1. **투구 기록과 마크** — 투구 전후에 서 있던 핀 수의 차이를 이번에 쓰러진 핀 수로 기록합니다. 새 랙의 핀 10개를 한 번에 쓰러뜨리면 스트라이크, 앞선 투구에서 남긴 핀을 모두 쓰러뜨리면 스페어, 새로 쓰러진 핀이 0개면 미스입니다. 스플릿은 새 랙에서 일부 핀이 남았을 때 제공된 `IsSplit(mask)`로 판정합니다. 경기 시작 전·종료 후·핀 준비 중에 들어온 결과나 투구 전에 없던 핀이 다시 나타난 결과는 기록하지 않습니다.
2. **점수 계산** — 1~9프레임에서 일반 프레임은 두 투구를 합산합니다. 스트라이크는 10점에 다음 두 투구, 스페어는 10점에 다음 한 투구를 더합니다. 보너스 투구가 부족하면 점수를 미확정으로 표시하고, 누적 점수는 첫 프레임부터 연속으로 확정된 프레임까지 합산합니다.
3. **1~9프레임 진행** — 첫 투구가 스트라이크면 즉시 다음 프레임으로 넘어가 핀 10개를 세웁니다. 첫 투구에 핀이 남으면 그대로 두고 둘째 투구를 진행합니다. 둘째 투구가 끝나면 다음 프레임을 위해 핀 10개를 세웁니다.
4. **10프레임 진행** — 첫 두 투구가 스페어면 핀 10개를 세우고 한 번 더 던집니다. 첫 투구가 스트라이크면 핀 10개를 세우고 두 번 더 던집니다. 이때 둘째도 스트라이크면 셋째 전에 다시 세우고, 둘째가 7핀이면 셋째는 남은 3핀을 사용합니다. 첫 두 투구가 일반 프레임이면 추가 투구 없이 끝납니다. 10프레임 점수는 허용된 투구를 모두 합산하고, 마지막 투구 후 경기를 종료합니다.

## 3. 빌드

1. **File → Build Profiles**에서 Windows를 선택합니다.
2. Scene List에 `Assets/BowlingGame/Scenes/BowlingHallPractice.unity`를 추가하고 활성화합니다.
3. **Build And Run**을 눌러 `bowling-game/Builds/Windows/`에 출력합니다.
4. 실행 파일을 열어 투구와 점수판을 확인합니다. 실행 파일을 공유할 때는 함께 생성된 데이터 폴더도 포함합니다.

## 4. 선수 지식

| 개념 | 먼저 확인할 내용 |
| --- | --- |
| 볼링 점수 규칙 | 스트라이크·스페어 보너스, 10프레임 추가 투구와 핀 재배치 |
| 비트 마스크 | 투구 전후에 서 있는 핀 읽기, 제공된 `CountPins()`와 `IsSplit()` 사용 |
| 리스트와 인덱스 | 1부터 시작하는 프레임·투구 번호와 리스트 인덱스 구분, 보너스 투구가 아직 없을 때의 처리 |
| 경기 진행과 점수 확정 | 다음 투구·다음 프레임·경기 종료 구분, 미확정 점수와 확정된 0점 구분 |

### 경기 규칙 참고

한 경기는 **10프레임**입니다. 프레임은 점수를 매기는 단위이고, 롤은 공을 한 번 던지는 단위입니다. 새 랙은 핀 10개를 모두 세운 상태입니다.

#### 투구 판정

| 판정 | 조건 |
| --- | --- |
| 미스 | 이번 투구에 새로 쓰러진 핀이 0개입니다. |
| 스트라이크 | 새 랙의 핀 10개를 한 투구로 모두 쓰러뜨립니다. |
| 스페어 | 같은 랙에서 첫 투구에 남긴 핀을 둘째 투구로 모두 쓰러뜨립니다. |
| 스플릿 | 새 랙에서 일부 핀이 쓰러진 뒤 남은 배치가 제공된 `IsSplit(mask)` 판정을 만족합니다. 예를 들어 7번과 10번 핀만 남은 경우입니다. |

핀 수는 이번 투구 직전과 직후에 서 있던 핀 수의 차이입니다. 첫 투구에 7핀, 둘째에 2핀을 쓰러뜨렸다면 둘째 롤에는 2핀을 기록하고 프레임에는 9점을 기록합니다.

#### 프레임과 롤 진행

| 상황 | 다음 동작 |
| --- | --- |
| 1~9프레임 첫 투구에 스트라이크 | 다음 프레임의 첫 롤로 이동하고 핀 10개를 세웁니다. |
| 1~9프레임 첫 투구에 핀이 남음 | 남은 핀으로 같은 프레임의 둘째 롤을 진행합니다. |
| 1~9프레임 둘째 투구 완료 | 다음 프레임의 첫 롤로 이동하고 핀 10개를 세웁니다. |
| 10프레임 첫 두 투구의 합이 10 미만 | 둘째 롤에서 경기를 종료합니다. |
| 10프레임 첫 두 투구가 스페어 | 핀 10개를 세우고 셋째 롤을 진행합니다. |
| 10프레임 첫 투구에 스트라이크 | 핀 10개를 세우고 둘째 롤을 진행합니다. 둘째도 스트라이크면 셋째 전에 핀 10개를 세우고, 그 외에는 둘째 투구에서 남은 핀으로 셋째 롤을 진행합니다. |

10프레임의 추가 롤은 10프레임에 속합니다. 마지막 허용 롤을 기록하면 경기가 끝납니다.

#### 점수 책정

| 프레임 결과 | 점수 | 예시 |
| --- | --- | --- |
| 1~9프레임 일반 프레임 | 두 롤의 핀 수 합계 | 7핀, 2핀은 9점 |
| 1~9프레임 스페어 | 10점 + 이후 첫 롤의 핀 수 | 7핀, 3핀 뒤 다음 롤이 4핀이면 14점 |
| 1~9프레임 스트라이크 | 10점 + 이후 두 롤의 핀 수 | 스트라이크 뒤 3핀, 4핀이면 17점. 다음 두 롤은 서로 다른 프레임에 있을 수 있습니다. |
| 10프레임 | 해당 프레임에 기록된 2회 또는 3회 투구의 핀 수 합계 | 10핀, 7핀, 3핀은 20점 |

보너스에 필요한 투구가 아직 없으면 해당 점수는 **미확정**입니다. 두 롤이 모두 0핀인 일반 프레임은 **확정된 0점**입니다. 누적 점수는 첫 프레임부터 연속으로 확정된 프레임까지 더합니다.
