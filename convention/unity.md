# Unity / C# 코딩 컨벤션

볼링·레이싱·매치 3 주차에 적용할 Unity / C# 컨벤션 원본입니다. Unreal 프로젝트 경험이 있는 참여자도 배포 프로젝트의 C#·Unity API를 기준으로 작성하며, 합의한 규칙을 추가·수정합니다. 현재 01주차 Pong은 이 문서가 아니라 `convention/sfml.md`를 따릅니다.

## 원본과 적용 방법

- 원본은 `main` 브랜치의 `convention/unity.md`입니다.
- Unity 주차의 `convention.md`는 원본의 복사본입니다. 규칙을 바꿀 때는 main 원본을 먼저 수정한 뒤 해당 주차 복사본을 갱신합니다.
- SFML / C++ 규칙은 `convention/sfml.md`에서 따로 관리합니다. C++의 접근 지정자·할당 연산자 배치 규칙을 C#에 그대로 적용하지 않습니다.

## 현재 적용 범위

명명·멤버 배치 규칙은 아직 정하지 않았습니다. 아래 제어문·블록·예외 처리 규칙부터 적용하고 합의한 항목을 추가합니다.

## 조건문·블록·예외 처리

- 한 문장짜리 if도 본문을 다음 줄에 들여 씁니다. else·else if도 같은 규칙을 적용합니다.
- 블록의 여는 중괄호와 닫는 중괄호는 각각 별도 줄에 두고 내용은 그 사이 줄에 작성합니다. 객체·컬렉션 초기화의 중괄호와는 구분합니다.
- try/catch는 최대한 사용하지 않습니다. 일반 분기는 조건·반환값으로 처리하고 불필요한 재던지기·중첩 catch는 피합니다. 실제 복구·진단·정리가 필요한 경계에서만 처리합니다. C#의 자원 정리는 using·IDisposable 등 해당 언어의 수명 관리 방법을 사용합니다.

```csharp
if (target == null)
    return;

if (target.activeSelf)
{
    target.SetActive(false);
}
```
